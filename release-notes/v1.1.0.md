## BMS v1.1.0

### ✨ New
- **Registration:** the login page has a **Registration** button next to **Login**. A new user fills in name, username and password, then waits. They can log in only after the admin approves them.
- **Approve or reject:** the Users page shows new registrations in a "Waiting for approval" list. The admin picks the role when approving. A rejected registration is deleted.

### 🔄 Changes
- **Users page:** waiting, active and inactive users now sit side by side.
- **Login page:** simpler header; Login and Registration buttons side by side.
- **Row details on hover:** long text no longer makes the box as tall as the screen.

## BMS v1.1.0

### ✨ নতুন
- **রেজিস্ট্রেশন:** লগইন পাতায় **লগইন**-এর পাশে **রেজিস্ট্রেশন** বোতাম। নতুন ইউজার নাম, ইউজারনেম আর পাসওয়ার্ড দেবে। অ্যাডমিন চালু করলে তবেই লগইন করতে পারবে।
- **চালু বা নাকচ:** ইউজার পাতায় "রেজিস্ট্রেশনের অপেক্ষায়" তালিকায় নতুন রেজিস্ট্রেশন দেখাবে। চালু করার সময় অ্যাডমিন ভূমিকা বেছে দেবে। নাকচ করলে রেজিস্ট্রেশন মুছে যাবে।

### 🔄 পরিবর্তন
- **ইউজার পাতা:** অপেক্ষায়, চালু আর বন্ধ ইউজারের তালিকা এখন পাশাপাশি।
- **লগইন পাতা:** উপরের অংশ সহজ; লগইন আর রেজিস্ট্রেশন বোতাম পাশাপাশি।
- **সারির উপর মাউস রাখলে বিস্তারিত:** লম্বা লেখা থাকলে বক্সটা আর পুরো স্ক্রিন জুড়ে লম্বা হয় না।
